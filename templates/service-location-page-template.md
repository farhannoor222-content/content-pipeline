# Service-Specific Location Page Template

Use this template for a page targeting one specific service in one specific city (e.g., "Tree Trimming in Winfield, PA"). This is separate from location-page-template.md, which covers all services together for a city.

These pages are for the client's Main Targeted City, unless the person names a different city when requesting the page. Apply all rules in tone-and-qa-rules.md, including the Service Definitions section, to every section below.

Before writing, check the client's Pattern and Angle Tracker in pipeline-notes.md the same way as for general location pages, and add a row after finishing.

## Population Tiers for This Template

- Tree Trimming, Tree Removal, Emergency Tree Service pages: use the same population tiers as location-page-template.md (Tier 1 under 5,000 = 1 sentence, Tier 2 5,000 to 20,000 = 2 sentences, Tier 3 over 20,000 = 3 sentences) for the "Our [Service] Services" section.
- Stump Grinding, Stump Removal, Crane Service, and any other service page: always use the Tier 2 word count (2 sentences), regardless of the city's actual population.

These tiers apply only to the "Our [Service] Services" section (Trimming and Removal pages). The Customized Local Heading and Why Choose sections have fixed lengths.

## Page Structure

### Meta Description
24 words. Must include the exact service name and "[City, State]."

### H1: [Service Name] in [City, State]
40 words. Must include the exact phrase "[service name] in [City, State]." Use the same 5 opening patterns and transition rule as location-page-template.md, rotated the same way, scoped to this one service rather than tree service generally.

### Trust Badges
Same as location-page-template.md: 4 short bullets, 3 to 4 words each, right after the H1.

### H2: Customized Local Heading
Same rules as location-page-template.md (angle rotation, expertise framing rule, depth rule, local-reference rule, order rule), but every example and local tie-in should relate specifically to this one service, not tree service in general.

Body: 100 to 120 words. Fixed length, not tiered.

### H2: Our [Service] Services, Trimming and Removal pages only
Include this section only when the page's service is Tree Trimming or Tree Removal. Skip it entirely for every other service page (Stump Grinding, Stump Removal, Tree Cutting, Emergency Tree Service, Crane Service, or any other single service) and go directly from the Customized Local Heading to Why Choose Us.

Tree Removal page: cover removal types as H3s, such as Hazardous Tree Removal, Dead Tree Removal, Leaning Tree Removal, and Large Tree Removal. Use the client's own service list if it defines these types differently.

Tree Trimming page: cover trimming techniques as H3s. Use the client's own service list if it names specific techniques; otherwise use standard techniques such as Crown Thinning, Crown Raising, Crown Reduction, and Deadwooding, adapted with real local research where relevant.

Follow the same Action rule and Species rule as the "Our Services" section in location-page-template.md: every H3 description must state a business action, not just a fact, and any species reference should name 2 to 3 species, not one.

(tiered) word count per the Population Tiers section above.

### H2: Why Choose [Business Name]
Same as the "Why Choose [Business Name]" section in location-page-template.md (same angle options, same rotation rule), except the length is fixed: always use the Tier 2 count, 2 sentences per USP H3, regardless of the city's population.

### H2: Our Working Process
Identical to the "Our Working Process" section in location-page-template.md: same angle options, same even-steps-only rule (4 or 6), same rule against using a USP as a step.

### H2: Frequently Asked Questions
3 to 4 questions, same format and per-answer rules as location-page-template.md (direct factual first sentence, "we/our" business action in the second sentence).

Scope every question to this one service only, not tree service generally. The mandatory cost question is about this service's cost specifically. Rotate the 2 to 3 remaining questions from topics relevant to this service (timing, process, permits, insurance, what to expect), sourced from the client profile and competitor research the same way as location-page-template.md. If the client profile has no pricing reference for this service, research a real local or regional average price range via web search instead of skipping the number. Never invent a number.

### No "We Serve Every Corner of [City]" Section
Skip this section entirely on service-specific pages. It only appears on the general location page template.

Use the same tracker table as location-page-template.md in the client's pipeline-notes.md. Add a "Page Type" column if it isn't already there, so service-specific pages and general location pages can be told apart in the tracker.
